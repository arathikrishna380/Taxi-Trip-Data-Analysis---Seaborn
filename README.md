# 🚖 Taxi Trip Data Analysis & Visualization
---

## 📌 Project Overview
This project processes and analyzes a real-world taxi dataset (NYC Taxis). It covers the complete data science workflow—from data cleaning and missing value imputation to generating comprehensive univariate, bivariate, and multivariate visualizations.

---

## 🛠️ Tech Stack & Libraries
* **Python** (Core logic)
* **Pandas** & **NumPy** (Data manipulation and cleaning)
* **Matplotlib** (Base plotting)
* **Seaborn** (Advanced statistical data visualization)

---

## 📊 Visualizations Included

1. **Line Chart:** Visualizes taxi fare trends over time using converted datetime stamps.
2. **Bar Chart:** Displays total fare revenue aggregated by pickup boroughs.
3. **Pie Chart:** Illustrates trip distribution percentages across various payment methods.
4. **Histogram:** Evaluates the statistical distribution and granularity of trip distances.
5. **Box Plot:** Analyzes tip amount spreads, medians, and outliers grouped by pickup borough.
6. **Count Plot:** Compares the total volume of trips originating from each borough.
7. **Scatter Plot:** Maps the correlation between trip distance and fare, categorized by borough.
8. **Correlation Heatmap:** Highlights statistical relationships between numerical features (`distance`, `fare`, `tip`, `tolls`, `total`).
9. **Pair Plot:** Explores pairwise multi-variable distributions across dataset metrics.
10. **Violin Plot:** Contrasts the probability density of fares across different payment types.
